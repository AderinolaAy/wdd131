RHADER Records Site Plan

Site Name: RHADER Records

RHADER Records is a modern music label and hub for artists, fans, and producers. The name was chosen to represent creativity, rhythm, and identity in the music industry.

Optional domain availability: rhaderrecords.com

Site Purpose

The site will serve as a digital home for RHADER Records, showcasing artist profiles, new releases, event updates, and a contact form for collaborations. It will also provide streaming links and merchandise information.

Scenarios

  • Where can I listen to the latest RHADER Records releases?
  • How can I contact RHADER Records for booking or collaboration?

Color Schema

Primary Color: #1DB954 (Spotify Green) – used for headings, buttons, and accents.

Secondary Color: #121212 (Dark Charcoal) – used for background and navigation.

Accent Color: #FFFFFF (White) – used for body text and contrast.

Typography

Heading Font: Oswald – bold and modern, used for titles and section headings.

Body Font: Roboto – clean and readable, used for paragraphs and general content.

Wireframes

Mobile View

[Logo at top, hamburger menu, featured artist section, latest releases block, footer with social links]

Desktop View

[Logo top-left, horizontal navigation bar, hero banner with featured artist, grid layout for releases, sidebar for events, footer with contact info]

Testing

This site plan will be validated for HTML structure, accessibility, color contrast, SEO basics, and performance using tools like W3C Validator, Lighthouse, and browser dev tools.
